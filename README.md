# Лабораторная работа №1 — RPN Calculator (TDD)

Консольное приложение на C#, реализующее калькулятор для выражений,
записанных в **обратной польской записи** (Reverse Polish Notation,
вариант 2). Разработка велась по методике TDD с использованием xUnit;
каждый этап «красный → зелёный» зафиксирован отдельным коммитом.

## Структура решения

```
PostfixCalculator.sln
├── src/
│   └── PostfixCalculator/              # консольное приложение + библиотека
│       ├── ICalculator.cs              # спецификация интерфейса
│       ├── Calculator.cs               # реализация RPN-калькулятора
│       └── Program.cs                  # точка входа
└── tests/
    └── PostfixCalculator.Tests/        # xUnit-тесты (Given/When/Then)
```

## Сборка и запуск

```bash
dotnet build
dotnet test
dotnet run --project src/PostfixCalculator -- "3 4 + 2 *"
```

## Поддерживаемые операции

`+`, `-`, `*`, `/` — бинарные операции над вещественными числами.
Токены в выражении должны быть разделены пробелами.

## TDD-последовательность коммитов

1. Спецификация интерфейса и каркас решения.
2. Тесты для двух операндов и одной операции (*красный*).
3. Реализация для двух операндов и одной операции (*зелёный*).
4. Тесты для трёх операндов и двух операций (*красный*).
5. Реализация для трёх операндов и двух операций (*зелёный*).
6. Тесты для произвольных сложных выражений (*красный*).
7. Обобщённая стек-ориентированная реализация (*зелёный*).
